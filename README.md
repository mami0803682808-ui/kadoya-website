## 3. サイトの方向性・デザイン

角屋は昔ながらの食堂だが、サイトは古臭くせず、**黒基調・上品・和モダン・高級感のある見せ方**を基本とする。

重要なデザイン意図：
- 実物の角屋ロゴ／家紋をブランドの核として使う。
- トップは縦書き「角屋」＋家紋の印象的な演出。
- スクロールに合わせてトップのサインが消える演出がある。
- 店内の黒竹など、実店舗の雰囲気とサイトの世界観を合わせる。
- 料理写真を主役にし、余計な装飾・説明を増やしすぎない。
- PCだけでなくスマホ表示を非常に重視する。
- スマホ上部ヘッダーはスクロール方向に応じた表示制御をしているため、変更時に挙動を壊さない。
- 料理カードは原則 **写真4:3**、商品名・価格のサイズと位置を揃える。
- カード全体を不用意にリンク化しない。

## 7. 写真・メニューカードの重要ルール

過去に写真サイズやカード高さがバラバラになる問題が多かったため、以下は崩さないこと。

- 料理写真は原則4:3。
- `object-fit` 等による料理の不自然な見切れに注意。
- PC / スマホで写真枠の比率を揃える。
- 商品名・価格のフォントサイズ、位置、余白をカテゴリ間で統一。
- 長い商品名は無理に1行にせず2行表示可能にする。
- 一品料理だけ写真が小さくなる旧ルールは復活させない。
- 新しい写真を追加したら既存カードと高さ・幅を比較する。
