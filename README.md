# 角屋 公式Webサイト

愛知県小牧市の食堂「角屋」公式Webサイト用リポジトリです。

## 現在の状態（2026-10-01）
- 実写真を多数反映済み
- スマートフォン対応
- スクロール／ホバーアニメーション対応
- お品書きはカテゴリ別に整理済み
- きしめん・夏季限定・単品など、写真サイズ／商品名／価格位置の統一を継続調整中
- 丼もの等の重複表示を整理済み
- リッチチョコフラッペはモーニングメニューから削除済み
- 年越し蕎麦など一部は Coming Soon 表示を使用
- Cloudflare Pages + 独自ドメインでの公開を予定

## 主なファイル
- `index.html`：ページ本体
- `style.css`：全体デザイン・各メニューカード・レスポンシブ調整
- `script-base.js`：メニュー等の主要ロジック
- `script.js`：追加の表示調整・挙動
- `images/`：料理・店舗写真
- `videos/`：店内動画等
- `HANDOFF.md`：別アカウント／別AIへ作業を引き継ぐための最新メモ

## 作業時の重要事項
- 作業前に必ず `main` の最新状態を確認すること。
- 過去版をベースに上書きして、最新のメニュー・季節タブ・写真・価格修正を戻さないこと。
- メニューカードは、写真サイズ・商品名の位置・文字サイズ・価格表記を同カテゴリ内で統一すること。
- 既に削除した文言や重複メニューを復活させないこと。

詳細な引き継ぎ内容は `HANDOFF.md` を参照してください。
