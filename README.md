# 角屋 公式Webサイト

愛知県小牧市の食堂「角屋」の公式Webサイトです。

## Website
- https://komaki-kadoya.com

## 構成
- `index.html` — ページ本体
- `style.css` — デザイン・レスポンシブ対応
- `script.js` / `script-base.js` — 表示・操作ロジック
- `images/` — 料理・店舗画像
- `videos/` — 店舗紹介動画
- `_headers` — Cloudflare Pages セキュリティヘッダー

## Hosting
Cloudflare Pages で公開しています。
